Dashboard

La pantalla principal muestra un resumen visual de la situación financiera del usuario para un período seleccionado (mes/año).

Componentes

Información del Usuario: Nombre, saldo actual, selector de período.

Donut Chart: Visualización circular mostrando distribución de gastos por pilar con colores distintivos.

Tarjetas de Pilares: Cada pilar (Fijos, Deuda, Ahorro, Ocio, Varios) con porcentaje gastado y monto.

Sección Movimientos: Últimos 10-15 movimientos con descripción y monto.

Movimientos

Página para ver, filtrar y gestionar el historial completo de transacciones con filtros por categoría.

Componentes

Header: Título + Selector de período

Filtros: Tags dinámicos de categorías (clickeables para filtrar)

Botón "Limpiar Filtro": Aparece cuando hay 2+ filtros seleccionados (alineado a derecha)

Lista de Movimientos: Agrupados por fecha, con categoría y monto

Flujo de Filtrado

Sin Filtro: Muestra todos los movimientos del mes
1 Filtro: Tag de categoría, botón "→"
2+ Filtros: Botón "Limpiar Filtro" aparece en lugar del →
Click en Categoría: Navega a página de categoría específica (future)

Persistencia

Datos de Usuario

Se guardan en userStorage utility. Disponible para toda la aplicación. En futuro, se sincronizarían con backend.

Categorías

Gestor completo de categorías organizadas por pilar. Permite crear, editar y eliminar categorías personalizadas.

Estructura

Las categorías se organizan dentro de cada pilar (Fijos, Deuda, Ahorro, Ocio, Varios). Cada pilar es expandible mostrando sus categorías.

Operaciones

Crear: Click en "+" → Abre AddCategoryPage → Selecciona pilar → Ingresa nombre → Guarda
Editar: Click en categoría → AddCategoryPage modo edición → Actualiza nombre
Eliminar: Long-press o ícono ✕ → Confirmación → Elimina categoría

Data Architecture

useCategories() Hook

Hook independiente que gestiona estado de categorías. Inicializa desde ALL_CATS (constante). Métodos: addCategory(), deleteCategory(), editCategory(). En futuro conectaría a base de datos.

Presupuestos

Página para definir y gestionar presupuestos mensuales para pilares y categorías individuales.

Dos Niveles de Presupuestos

Presupuestos de Pilares: Monto total para cada pilar. Persisten entre recargas en localStorage.

Presupuestos de Categorías: Monto individual por categoría. Persisten durante la sesión en sessionStorage, se reinician al recargar.

UI/UX

Tarjeta de Pilar: Expandible, muestra monto total del pilar
Al Expandir: Muestra lista de categorías del pilar con inputs individuales
Placeholder: "Presupuesto" (con 60% opacidad) cuando valor es 0
Botón Guardar: Circular flotante (✓) solo se activa cuando hay cambios

Code Architecture

usePillarBudgets() Hook

Gestiona presupuestos de pilares. Guarda en localStorage con clave "orus_pillar_budgets". Persiste entre sesiones.

useBudgets() Hook

Gestiona presupuestos de categorías. Guarda en sessionStorage con clave "orus_category_budgets". Se reinicia al recargar la app.

Mostrar Ingresos

Página dedicada para visualizar y gestionar ingresos. Accesible desde Configuraciones con toggle en el título.

Características

Toggle en Título: Controla si se muestran ingresos en el dashboard y reportes

Descripción: "Visualiza los ingresos que entran en el período seleccionado. Si el ingreso supera el gasto, también mostrará el saldo restante."

Contenido: Por ahora vacío (preparado para futuras features como gráficos de ingresos)

UI Exception

Layout Especial

Esta es la ÚNICA página donde el toggle aparece en el título (lado derecho). Todas las demás páginas siguen el layout estándar: título centrado + descripción debajo.

Navigation

Acceso: Settings → Click en "Mostrar Ingresos" (excepto el toggle) → Navega a ShowIncomesPage
Toggle: Funciona en ambas ubicaciones (Settings y ShowIncomesPage)

Principios Arquitectónicos

Sin estado en App.jsx: App solo maneja navegación. Todo estado vive en hooks independientes (useCategories, useBudgets, usePillarBudgets).

Servicios Globales: PopupService proporciona notificaciones a toda la app mediante React Context.

Datos Centralizados: pageHeaders.js contiene metadata de todas las páginas (título, icono, descripción, hints).

Cálculos Separados: Lógica de negocio (calculateDashboard, getPillarPercentage) vive en utils/, no en componentes.

Persistencia Flexible: Cada hook maneja su propia persistencia (localStorage, sessionStorage, o memoria).

PageHeader - Componente Reutilizable

Props

icon, title, description, hint, isDark, onDescriptionHeightChange, showTitleToggle, toggleValue, onToggleChange

Características

Renderiza título centrado (o title + toggle a derecha para Mostrar Ingresos), descripción dinámica que mide altura automáticamente, maneja su propio ref para sincronizar posición de contenido. Evita duplicación de código entre páginas.

Flujos de Datos Principales

1. Crear Nueva Categoría

CategoriesPage → Click "+" → AddCategoryPage (modo nuevo)
Usuario ingresa nombre y pilar → Click Guardar
onSave callback → App.jsx llama addCategoryToHook()
useCategories actualiza state → categories[pillarId].push(newName)
App re-renderiza → pasa nuevo categories a BudgetsPage via prop
BudgetsPage detecta cambio en useEffect → llama updateWithNewCategories()
useBudgets agrega nueva categoría a categoryBudgets con presupuesto 0
Nueva categoría visible inmediatamente en BudgetsPage ✅

2. Editar Presupuesto de Categoría

BudgetsPage → Click en input de categoría → Edita valor
onChange → handleCategoryBudgetChange() actualiza categoryBudgets en memoria
useEffect en useBudgets → guarda a sessionStorage automáticamente
Usuario navega a otra pantalla
Vuelve a BudgetsPage → useBudgets carga de sessionStorage
Presupuesto editado se recupera ✅ (persiste en sesión)
Usuario recarga app (F5) → sessionStorage se borra → presupuesto vuelve al default

3. Gestionar Toggle Mostrar Ingresos

Settings → Click en "Mostrar Ingresos" (no el toggle) → Navega a ShowIncomesPage
ShowIncomesPage recibe showIncomesEnabled y onToggleShowIncomes
Click en toggle (en el título) → onToggleShowIncomes(newValue)
App.jsx actualiza state showIncomes → re-renderiza todas las páginas
Dashboard ahora muestra/oculta sección de Ingresos según el toggle
